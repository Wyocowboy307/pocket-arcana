# Card Design Rules — “Magic-level expression, kid-readable cards”

## Complexity budget
- **Common:** normally one idea, one sentence.
- **Uncommon:** one idea plus a visible synergy.
- **Rare:** may build an engine or bend a normal expectation.
- **Mythic:** memorable spectacle or deck-defining payoff; still explainable without a paragraph.

## Numbers baseline
Stats/costs are playtest knobs, not identity. Prefer a simple baseline creature curve, then charge a stat cost for strong immediate effects. Do not solve balance by making every new set numerically stronger.

## Good Pocket Arcana effect
A good effect does at least one of:
- changes a visible tile;
- changes positioning;
- creates a creature/landmark the player can see;
- interacts with a Commander/deck plan;
- creates a meaningful Pass/hand-conservation decision;
- opens another understandable combination.

## Avoid
- walls of rules text;
- coin-flip casino cards with no tactical choice;
- invisible counters players must remember;
- “same card but +1 stat” filler;
- direct copies of another game's iconic cards/mechanics/names;
- keywords that exist only to sound like a TCG.

## Element identity guardrails
- Frost controls/preserves; it should not be best at raw Heart burn.
- Lightning sets up/bursts; it can be fragile.
- Life heals/grows; it should need board presence for its biggest payoffs.
- Fire pressures/destroys; it pays for speed with fragility/card use.
- Water draws/repositions; it should win through flexibility rather than biggest base stats.
- Earth fortifies/builds; it should be slower and positional.
- Wind moves/evades; it should reward planning routes.
- Death recurs/sacrifices; it should gain value from loss instead of simply being “purple Fire.”

## Dual-element rule
A dual card should feel like a sentence neither element would write alone. Example: Life/Fire does not merely “heal 2 and deal 2”; it **grows something, burns it, and rewards the transformation**.

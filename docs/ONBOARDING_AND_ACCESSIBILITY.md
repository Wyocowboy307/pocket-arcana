# Onboarding & Accessibility

## Rule: same game, better teaching
Do not create a dumbed-down ruleset for kids. Teach the normal game through UI.

### First-match learning order
1. **Play a card.** Click card → glowing legal tile.
2. **Shape.** Explain only: “Shape makes the element your deck needs.”
3. **Move.** One tile at a time.
4. **Pass.** Explain: “Save cards for the next Chapter.”
5. **Recipes.** Let the player cause one guaranteed two-state transformation.
6. **Commander.** One button, once per Chapter.

### UI rules
- Legal moves glow. Illegal attempts give a plain-English reason.
- Card text aims for one sentence; advanced explanation lives in tooltip/Codex.
- Icons always have text labels available.
- Show a predicted recipe name after the player has discovered that recipe once.
- Use consistent elemental color + icon + word; never color alone.
- “Pass” must show what happens: current Realm Score and estimated Chapter result.
- Large readable default text; controller and touch targets should be generous.
- Animation may clarify state, but the player never has to infer a rule from animation alone.

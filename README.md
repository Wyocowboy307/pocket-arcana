# Pocket Arcana

**Standalone Godot project. Never place this inside Pixel Ranch.**

Pocket Arcana is a 2D pixel-art living-board collectible card game: easy to understand at a glance, deep enough to support serious deckbuilding. Players shape an elemental world, summon creatures and landmarks into real board positions, mix elemental states into discovered terrain, protect or break persistent Hearts, and decide when to pass to preserve cards across a best-of-three Chapter match.

## Current build package
- Godot 4.7.2 graybox project with `project.godot` + runnable `scenes/main.tscn` target
- 7×5 living board simulation
- best-of-three Chapter / pass model
- persistent 25-point Heart, 10-Wonder alternate victory, Chapter Seals
- 8 elements: Frost, Lightning, Life, Fire, Water, Earth, Wind, Death
- 240-card design pool (32 marked slice-ready)
- 24 Commanders (3 per element)
- 8 legal 40-card starter decks
- 28 two-element terrain recipes
- 12 tokens
- deterministic simple AI shell
- mouse-driven graybox UI generated by `scripts/ui/main.gd`
- content validator + audit tools

## Before Claude changes anything
1. Read `CLAUDE.md`.
2. Run `python3 tools_validate_content.py`.
3. Run `python3 tools_content_audit.py`.
4. Open the project in Godot.
5. Fix parser/runtime issues before redesigning anything.

## Important honesty
This package has been structurally validated with Python, but the current environment does **not** contain a Godot executable, so the first real Godot parser/runtime pass must happen on the machine where Godot is installed. The code is intentionally graybox-first and data-driven so that pass is small and reversible.

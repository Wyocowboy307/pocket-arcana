# Collection & Replay Loop

## Why keep playing
1. Duel, puzzle, expedition or campaign encounter.
2. Earn cards, Commander mastery XP, cosmetic materials and Codex discoveries.
3. See a new recipe or creature interaction.
4. Build/change a deck around it.
5. Unlock a new opponent/region/puzzle.

## Collection principles
- Players should be able to build decks, not only copy starters.
- New cards should create new *plans*, not simply higher numbers.
- Commander unlocks can use earnable game currency.
- Commander levels unlock presentation/lore/sidegrades, never raw PvP stat advantage.
- If monetization is ever added, keep paid power out of the competitive rules.

## Long-tail modes
- Constructed campaign
- Puzzle boards
- Draft/Expedition
- Daily seeded challenge (later; only when save/backend needs are justified)
- Friendly/local AI gauntlets before networking
